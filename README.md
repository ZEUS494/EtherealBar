# ✨ EtherealBar

**EtherealBar** — это стильная и полностью настраиваемая панель быстрого доступа для Windows.  
Она «парит» поверх рабочего стола и превращает запуск приложений, игр и файлов в визуально приятный и быстрый процесс 🚀

Забудь про скучные ярлыки — теперь у тебя есть **интерактивные карточки с анимацией, видео и кастомным дизайном**.

---

## 🎯 Основные возможности

### 🎴 Интерактивные карточки
- Поддержка **изображений, GIF и видео**
- Идеально подходит для игр, приложений и любых файлов
- Живой и динамичный внешний вид рабочего пространства

### 🧩 Умная работа с графикой
- Поддержка **прозрачных PNG**
- Автоматическое скрытие фона — отлично для спрайтов персонажей
- **Кадрирование медиа** прямо внутри карточки

### 🎨 Гибкая кастомизация
- Настройка **шрифта, цвета и размера текста**
- Плавное позиционирование текста с помощью ползунка
- Единый стиль для всех карточек

### 🧠 Удобство использования
- **Drag & Drop**: перетаскивай карточки в реальном времени
- Быстрое редактирование и перестановка
- Интуитивный интерфейс без лишних действий

### 📂 Вкладки (рабочие пространства)
Создавай отдельные разделы:
- 🎮 Игры  
- 💻 Программы  
- 📄 Документы  

И переключайся между ними мгновенно

### 🌈 Визуальный стиль
- Акцентный цвет интерфейса (обводка + элементы управления)
- Настройка **прозрачности панели (вплоть до 0.00)**
- Минимализм или яркость — решаешь ты

### ⚙️ Окно настроек
- Перетаскиваемое окно (за верхнюю область)
- Быстрый доступ ко всем параметрам

### ⚡ Горячие клавиши
- Мгновенный вызов панели: **Alt + 1**

---

## 🚀 Запуск

Просто скачай и запусти файл:

👉 **EtherealBar.exe**

Никакой дополнительной настройки не требуется — приложение готово к работе сразу после запуска.

## 💡 Почему EtherealBar?

- Быстрее, чем стандартные ярлыки  
- Красивее, чем рабочий стол  
- Гибче, чем любые панели  

**EtherealBar — это не просто панель. Это новый способ взаимодействия с твоими приложениями.**
