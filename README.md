# EtherealBar

`EtherealBar` — это настраиваемая панель быстрого доступа для Windows. Она появляется поверх рабочего стола и позволяет запускать приложения и открывать файлы через карточки с изображениями и видео.

## Возможности

- Карточки с изображениями и видео
- Кадрирование медиа (выбор области отображения внутри карточки)
- Живое перетаскивание и перестановка карточек в режиме редактирования
- Вкладки (разделы) с разными рабочими пространствами: игры/программы/документы
- Акцентный цвет интерфейса (обводка + ползунки)
- Настройка цвета и прозрачности фона панели (вплоть до `0.00`)
- Окно настроек, перетаскиваемое за верхнюю область
- Быстрый вызов панели через `Alt+1`

## Запуск

Проект удобнее открывать через Visual Studio:

- решение: `EtherealBar.slnx`
- проект: `EtherealBar/EtherealBar.csproj`

Сборка из консоли:

```powershell
dotnet build .\EtherealBar\EtherealBar.csproj
```
