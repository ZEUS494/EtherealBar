# EtherealBar
Ваш рабочий стол, только чище. EtherealBar — это скрытая панель быстрого запуска, которая появляется только тогда, когда она вам нужна. Благодаря поддержке живых видео-фонов и неоновой подсветке, обычный лаунчер превращается в стильный элемент интерфейса, дополняющий эстетику вашего рабочего пространства.
