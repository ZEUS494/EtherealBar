# EtherealBar

`EtherealBar` — это настраиваемая панель быстрого доступа для Windows, которая появляется поверх рабочего стола и позволяет запускать приложения, файлы, изображения и видео-карточки в одном аккуратном интерфейсе.

## Возможности

- карточки с изображениями и видео
- настройка области отображения медиа внутри карточки
- свободная перестановка карточек в режиме редактирования
- настройка формата карточки и масштаба
- акцентный цвет интерфейса
- настройка цвета и прозрачности фона панели
- окно настроек с отдельным интерфейсом
- работа из трея
- быстрый вызов панели через `Alt+1`

## Запуск

Проект открывается через Visual Studio:

- решение: [`EtherealBar.slnx`](./EtherealBar.slnx)
- проект: [`EtherealBar.csproj`](./EtherealBar/EtherealBar.csproj)

Для локальной сборки можно использовать:

```powershell
dotnet build .\EtherealBar\EtherealBar.csproj
```
