# EtherealBar v1.2

## Что нового

- Добавлены вкладки (разделы) и отдельные рабочие пространства с разными наборами карточек.
- Переключение вкладок оптимизировано: видео корректно ставится на паузу и возобновляется при возврате.
- Прозрачность фона панели теперь можно выставить в `0.00` (полностью прозрачный фон).
- Размер карточек теперь подстраивается автоматически от высоты виджета.
- Исправлены артефакты верхней границы при прозрачном фоне.
- Добавлено ограничение минимальной высоты в режиме редактирования, чтобы кнопки не выходили за границы карточек.
- Настройки сохраняются в профиле пользователя (`LocalAppData`), чтобы установленная версия корректно сохраняла `settings.json`.

## Файлы

- Установщик Windows: `EtherealBar-Setup-1.2.0.exe`
