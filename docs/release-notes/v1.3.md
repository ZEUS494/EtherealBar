# EtherealBar v1.3.0 Release Notes

## Кастомизация текста
- Теперь вы можете выбрать любой системный шрифт для названий на карточках.
- Добавлен ползунок плавного позиционирования текста по вертикали.
- Размер шрифта теперь адаптивно подстраивается под высоту панели с возможностью дополнительного масштабирования.
- Выбор цвета текста через стандартную палитру.

## Работа с медиа
- Полноценная поддержка GIF-анимаций.
- Для PNG-изображений без фона теперь автоматически убирается фон самой карточки, делая их «прозрачными».
- Исправлено кадрирование для горизонтальных медиафайлов.

## Интерфейс и стабильность
- Добавлена возможность полностью отключить границы карточек.
- Минимальный размер панели зафиксирован на 320px для предотвращения скачков при редактировании.
- Автоматический выход из режима редактирования при закрытии панели.
- Отклик изменения размера панели стал мгновенным со ступенчатым шагом в 10 пикселей.
