# Релизы EtherealBar

Цель: чтобы в **GitHub Releases** всегда был только один файл: установщик Windows `*.exe`.

## Что прикладывать в релиз

Прикладываем только:

- `EtherealBar-Setup-<версия>.exe`

Ничего больше (архивы, portable‑сборки, `*.pdb` и т.д.) в релиз не добавляем.

## Текст релиза

Заметки релиза пишем для пользователей и на русском языке:

- что изменилось
- что исправлено
- если есть важные замечания по обновлению

Внутренние детали разработки (например, «добавлен скрипт Inno Setup») в релиз не выносим.

## Автоматическая чистка релиза (опционально)

Если в релиз случайно попали лишние ассеты, можно удалить всё, кроме `*.exe`, и обновить текст релиза через скрипт:

```powershell
.\tools\github\Update-GitHubRelease.ps1 -Tag v1.2 -NotesPath .\docs\release-notes\v1.2.md
```

Скрипт требует переменную окружения `GITHUB_TOKEN` (токен с правами на репозиторий).
