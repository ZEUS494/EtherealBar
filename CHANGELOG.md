# CHANGELOG

## [1.3.0] - 2026-04-11

### Добавлено
- Поддержка GIF-анимаций на карточках.
- Автоматическая прозрачность фона карточки для PNG-изображений.
- Глобальные настройки текста: выбор шрифта, цвета и масштаба.
- Плавное позиционирование текста на карточках с помощью ползунка «Верх — Низ».
- Настройка включения/выключения границ карточек в окне настроек.

### Исправлено
- Проблемы с кадрированием и масштабированием горизонтальных GIF/изображений.
- Автоматический выход из режима редактирования при скрытии панели (Alt+1).
- Синхронизирован минимальный размер панели для всех режимов (320px) для исключения скачков.
- Оптимизирована отзывчивость изменения размера панели (шаг 10px).

## [1.2.0] - 2026-04-01

- Добавлены вкладки (разделы) и рабочие пространства с разными наборами карточек.
- Переключение вкладок ускорено: медиа кэшируется, видео корректно ставится на паузу и возобновляется при возврате.
- Прозрачность фона панели теперь можно выставить в `0.00` (полностью прозрачный фон).
- Убрана ручная настройка размера карточек: размер подстраивается от высоты виджета автоматически.
- Исправлены артефакты верхней границы при прозрачном фоне.
- Добавлено ограничение минимальной высоты в режиме редактирования, чтобы кнопки не выезжали за границы карточек.
- Настройки приложения сохраняются в профиле пользователя (`LocalAppData`), чтобы установленная версия корректно сохраняла `settings.json`.
- Добавлен установщик Windows (.exe).

## 1.1.0

- Проект переименован в `EtherealBar`.
- Исправлена кодировка русского интерфейса и текстов меню.
- Улучшено редактирование карточек: живое перетаскивание и корректная работа карточек разной ширины.
- Добавлено окно кадрирования медиа для изображений и видео.
- Добавлены настройки акцентного цвета, цвета фона панели и прозрачности.
- Обновлён дизайн ползунков и окна настроек, добавлена возможность перетаскивать окно настроек за верхнюю область.
